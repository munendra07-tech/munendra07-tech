## 👋 About me

I'm a fresh AI & Data Science graduate who likes building software that keeps working when things go wrong. My recent work is about **making AI agents dependable**: testing how they behave when a tool call fails halfway, and giving chat assistants a long-term memory that is actually measured, not assumed.

I learn by shipping, so every project below is a working repository with tests, CI and documentation, not a notebook. I'm looking for an **AI / ML engineer or backend engineer** role where I can keep building and learning quickly.
